# Visual direction

The explorer is a quiet design workbench. Warm paper, charcoal type, fine rules, and one orange action control give the generated themes the visual focus. The three previews look like side-by-side printed studies, with the same sample page in each. The interface uses compact labels and generous space to support comparison without exposing Jev's probabilities.

The comparison now has four content stress tests. The page picker sits above the three previews so all interpretations change together. Each theme panel keeps its title, color marker, and copy action. Editorial tests reading, storefront tests catalog surfaces, and dashboard tests dense information. The sample pages are fictional and remain structurally identical across themes.

Gradient treatments use the theme palette on existing visual fields. Image frames alter the same image areas across previews through open, inset, outlined, panoramic, or captioned treatments. Both are selected as semantic options; the renderer owns all CSS.
