# Design review — preview pages

The four sample pages test different needs: persuasion, reading, shopping, and dense work. Their color system was mostly tonal. The new accent role uses a curated warm, cool, bright, deep, or soft choice, then resolves it against the selected base palette. The renderer keeps the accent distinct from the primary hue and gives accent labels a tested foreground color.

## Components to add next

1. **Expanded preview.** Three narrow columns make small type and controls hard to judge. Open one theme at a larger size while keeping the comparison view available.
2. **Control specimen.** Add search, select, checkbox, focus, disabled, validation, and empty states to a fixed page. The current samples cover buttons and one email field, so many token decisions remain untested.
3. **Semantic status set.** Add named success, warning, error, and information treatments. The new accent is for emphasis, not status meaning. The dashboard and storefront need clear examples of both.
4. **Media and icon system.** Test real image crops, captions, and a consistent icon set. Current geometric artwork is useful for palette comparison but cannot show how photographic content behaves.

The accent appears on a hero label, an editorial label and illustration, a product badge, and dashboard status and chart details. Each use has text or context, so meaning does not depend on color alone. Keep the accent on a few deliberate elements; making every button and card use it would weaken the hierarchy.
